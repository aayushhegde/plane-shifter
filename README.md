# Plane Shifter

A short narrative game inspired by Ursula K. Le Guin's *Changing Planes* (2003).

**Play it in your browser:** https://aayushhegde.github.io/plane-shifter/

The first load takes 10 to 20 seconds. Click the game once so it gets the keyboard.

Arrow keys move, E talks, SHIFT changes planes, J opens the journal.

Made with Python and pygame-ce, packaged for the web with pygbag.
